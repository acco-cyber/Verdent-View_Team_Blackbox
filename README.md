# 🌿 VerdantView

**VerdantView** by **Team Black Box** is a smart geospatial platform developed for the **NASA Space Apps Challenge 2025 – Bloom Watch**. It leverages the power of NASA’s satellite data and artificial intelligence to deliver actionable insights for sustainable agriculture.

🔗 **Live App**: [VerdantView Earth Engine App](https://top-chassis-470417-u2.projects.earthengine.app/view/verdent-view)  
🧪 **Run in GEE Code Editor**: [Google Earth Engine Playground](https://developers.google.com/earth-engine/guides/playground)

---

## 🚀 Overview

VerdantView transforms complex satellite data into intuitive visualizations and insights for:

- 🌾 Farmers — to monitor crop health and optimize harvest timing  
- 🧪 Researchers — to study vegetation dynamics and land use changes  
- 🏛️ Policymakers — to make informed decisions for sustainable land management

Built on **Google Earth Engine**, VerdantView integrates datasets like:

- [Sentinel-2](https://developers.google.com/earth-engine/datasets/catalog/sentinel-2?hl=en) — for high-resolution vegetation and land cover analysis  
- [Landsat-8](https://developers.google.com/earth-engine/datasets/catalog/landsat-8?hl=en) — for long-term environmental monitoring  
- [MODIS](https://developers.google.com/earth-engine/datasets/catalog/modis?hl=en) — for global vegetation indices and climate metrics

---

## 🧠 Features

- 📊 **Interactive Map** — dynamic visualization of agricultural zones  
- 🌱 **Crop Health Monitoring** — NDVI and other vegetation indices  
- 💧 **Soil Moisture Insights** — derived from multispectral analysis  
- 📅 **Harvest Timing Estimation** — based on phenological patterns  
- 🗂️ **Dataset Categorization** — organized access to multiple NASA datasets

---

## 🛠️ Technologies Used

- **Google Earth Engine (GEE)**  
- **NASA Satellite Data** (Sentinel-2, Landsat-8, MODIS)  
- **JavaScript API for GEE**  
- **AI/ML Models** for pattern recognition and forecasting
